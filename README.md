# Customer Churn Analysis

## Project Overview
Customer Churn Analysis is a data analytics project that identifies patterns and factors influencing customer subscription cancellations.

The project analyses customer behaviour, engagement, subscription types and payment patterns to understand why customers leave a service.

## Objectives
- Analyse customer churn rates.
- Identify subscription types with high churn.
- Understand the relationship between customer behaviour and churn.
- Examine customer engagement and payment delays.
- Suggest strategies to improve customer retention.

## Dataset
The dataset contains customer information, including:

- Customer ID
- Age and Gender
- Tenure
- Usage Frequency
- Support Calls
- Payment Delay
- Subscription Type
- Contract Length
- Total Spend
- Last Interaction
- Churn Status

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Charts
- GitHub

## Analysis Performed
1. Data Cleaning
2. Customer Churn Analysis
3. Subscription Type vs Churn
4. Contract Length vs Churn
5. Customer Behaviour Analysis
6. Data Visualisation

## Business Recommendations
- Improve customer support services.
- Provide attractive offers to customers at risk of leaving.
- Encourage customers to choose longer-term subscriptions.
- Improve customer engagement.
- Investigate reasons behind subscription cancellations.

## Conclusion
This project demonstrates how data analytics can help businesses understand customer behaviour, identify churn patterns and develop effective customer retention strategies.
